## 2. Стандарты и расширения glTF

Всё, что приложение умеет писать в файл, — с ссылкой на спецификацию расширения.
Именно эти имена появляются в отчёте и в предупреждении «нужен декодер на сайте».

| Расширение | Что делает | Спецификация |
|---|---|---|
| — | Сам формат glTF 2.0 | [спецификация](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) |
| `KHR_draco_mesh_compression` | Сжатие геометрии Draco | [спецификация](https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Khronos/KHR_draco_mesh_compression) |
| `EXT_meshopt_compression` | Сжатие геометрии meshopt | [спецификация](https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Vendor/EXT_meshopt_compression) |
| `KHR_texture_basisu` | Текстуры KTX2 / Basis Universal | [спецификация](https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Khronos/KHR_texture_basisu) |
| `EXT_mesh_gpu_instancing` | Инстансинг повторяющихся мешей | [спецификация](https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Vendor/EXT_mesh_gpu_instancing) |

Полный реестр расширений: [KhronosGroup/glTF — extensions](https://github.com/KhronosGroup/glTF/tree/main/extensions).

## 3. Целевые платформы

Что каждая умеет читать — это и определяет, какие опции ей вообще предлагать.
**Числа бюджетов и их проверка — отдельно, в `БЮДЖЕТЫ_источники.md`.**

### Движки — что каждый читает

Движок задаёт ПАЛИТРУ: какие опции вообще существуют. Площадка из этой палитры только
вычитает (`EXTENDING.md` §5d).

| Движок | Draco | Meshopt | KTX2 | Документация |
|---|:--:|:--:|:--:|---|
| **Three.js** | ✓ | ✓ | ✓ | [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) — требует явно подключить `DRACOLoader`, `KTX2Loader`, `MeshoptDecoder` |
| **model-viewer** (Google) | ✓ без настройки сайта | ✓ но нужен `setMeshoptDecoderLocation` | ✓ | [modelviewer.dev — loading](https://modelviewer.dev/examples/loading/) |

### Площадки с профилем

| Площадка | Движок | Документация | Состояние сверки |
|---|---|---|---|
| **Shopify** | model-viewer | [3D model standards checklist](https://help.shopify.com/en/partners/resources/creating-3d-models/3d-model-standards-checklist) · [Creating 3D models](https://help.shopify.com/en/partners/resources/creating-media/3d-models/creating-3d-models/3d-modeling-checklist) | размер файла, текстуры и материалы подтверждены; треугольники и отрисовки — нет |
| **VNTANA** | three.js | [VNTANA Help Center](https://help.vntana.com/) | предел файла подтверждён; Draco площадка не читает — опция вычитается, а не предупреждает |
| **Google Store** (карточка товара) | model-viewer | [web.dev — 3D and AR for commerce](https://web.dev/articles/model-viewer) | рекомендация по весу файла подтверждена; иных числовых целей документация не даёт |

**Удалены 2026-08-18: `mobile` и `quest`.** Класс устройства — не площадка: браузер
телефона и браузер шлема запускают тот движок, который выбрал САЙТ. Ни одного числа для
них первоисточником подтверждено не было — Meta для WebXR числовых целей не даёт вовсе
([WebXR Performance Best Practices](https://developers.meta.com/horizon/documentation/web/webxr-perf-bp/)).

### Технически подходят, профиля нет

| Движок | Draco | Meshopt | KTX2 | Документация |
|---|:--:|:--:|:--:|---|
| **Babylon.js** | ✓ | ✓ (5.0+ без настройки) | ✓ | [glTF Extensions в Babylon.js](https://babylonjs.medium.com/gltf-extensions-in-babylon-js-b3fa56de5483) · [GLTFLoaderExtensionOptions](https://doc.babylonjs.com/typedoc/interfaces/BABYLON.GLTFLoaderExtensionOptions) |
| **PlayCanvas** | ✓ | ✓ | ✓ (+ ASTC/ETC/DXT) | [PlayCanvas Engine](https://playcanvas.com/products/engine) |

### Решено не делать, никогда

**Sketchfab.** Площадка размещения, а не адрес доставки: она принимает исходник и
оптимизирует его СВОИМ конвейером. Оптимизировать модель перед загрузкой туда — работать
за неё же и вслепую, потому что итоговый файл делаем не мы.

**Unity и Unreal.** Оба импортируют GLB в собственный конвейер и пережимают всё заново по
своим настройкам — «бюджет GLB для Unreal» мало что означает, и обосновать его числами мы
не можем. Профиль — это JSON-файл: если понадобится, сообщество добавит его без правок кода.

Проверка, по которой площадка либо заводится, либо отсекается, — `EXTENDING.md` §5d:
это АДРЕС, куда отправляют модель? оптимизируем МЫ, а не они? числа взяты у первоисточника?
