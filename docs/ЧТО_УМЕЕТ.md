# Что приложение умеет сегодня

> Плоский список возможностей на текущий момент. Не журнал работ, не планы,
> не позиционирование (это `README.md`).
>
> Отвечает ровно на один вопрос: **«у нас это уже есть?»** — чтобы не искать ответ в коде
> и не спрашивать заново.
>
> **Версия дерева называется в `package.json` и больше нигде.** Раньше здесь стояло
> число, и оно отстало на три выпуска: документ, чья работа — отвечать «есть ли у нас
> это», сам держал устаревший факт в первой строке.
>
> **Обновлять при каждой новой возможности.** Строка устаревает молча, а верят ей как
> факту — это хуже, чем её отсутствие.

## Обработка

| Возможность | Есть | Как называется / чем делается |
|---|:--:|---|
| Безопасная чистка (дубликаты, мусор, сварка вершин, вырожденные треугольники) | ✓ | опция `safe` |
| Сжатие геометрии Draco | ✓ | `draco` |
| Сжатие геометрии Meshopt | ✓ | `meshopt` |
| Квантование геометрии | ✓ | `quantize`, `KHR_mesh_quantization` — единственный способ уменьшить геометрию **без декодера на сайте**; взаимоисключающий с Draco и Meshopt (те квантуют сами) |
| Сжатие текстур в KTX2 | ✓ | `ktx2`, режимы UASTC и ETC1S |
| Сжатие текстур в WebP | ✓ | `webp` — меньше файл при неизменной видеопамяти; потяжелевшая текстура возвращается к исходнику |
| Объединение мешей | ✓ | `join` |
| GPU-инстансинг повторяющихся мешей | ✓ | `instance`, `EXT_mesh_gpu_instancing`; порог — 2 узла на меш |
| Авто-выбор инстансинга, когда в модели общая геометрия | ✓ | значок «Советуем» (не путать с «В модели»: там технология уже в файле, здесь — ещё нет) |
| Умное объединение мешей: общая геометрия не размножается | ✓ | `join` объединяет только меши с одним владельцем; общие оставляет и сообщает об этом (`join.keptShared`) |
| Отказ структурных правил на неизвестном расширении | ✓ | дедупликация, чистка, объединение и инстансинг не работают, если файл объявляет расширение, которого не знает библиотека (`KHR_animation_pointer` и подобные адресуют свойства по номеру) |
| Прореживание ключей анимации | ✓ | `resample` |
| Уменьшение текстур | ✓ | `resize-4096` / `resize-2048` / `resize-1024` / `resize-512` — выбор одного из четырёх, по умолчанию не уменьшать. Уменьшается только то, что крупнее цели; пропорции сохраняются (цель — большая сторона); увеличение невозможно. Уже сжатые для видеокарты (KTX2) не трогаются — сначала уменьшить, потом сжимать. Необратимо, помечено `dataLoss: significant` |
| Чистка влияний костей | ✓ | входит в `safe`: повторная кость в вершине сводится в одну (`skin/joints-dedupe`), доли приводятся к единице (`skin/weights-normalize`), ссылки на кость с нулевой долей стираются (`skin/zero-weight-joints`) — на персонаже это десятки тысяч случаев |
| Перенос скиннутого меша в корень сцены | ✓ с оговоркой | `scene/skinned-mesh-root` переносит, только когда все преобразования над узлом единичные и неанимированные; на экспортах Sketchfab/FBX выше стоит обёртка с поворотом, и правило честно отказывается |
| Удаление вершинных цветов | ✓ | `strip-colors` |
| Всё выключено по умолчанию (passthrough) | ✓ | `advancedFeatures: []` |
| Проверка целостности результата | ✓ | сверка с контрольной точкой; при расхождении файл всё равно пишется, но помечается красным — решение за пользователем |
| Упаковка ORM (AO + roughness + metalness в одну текстуру) | ✗ | закрыто замером 2026-08-14: на 30 моделях и 282 материалах правило не сработало бы ни разу — экспортёры пакуют это сами |
| Генерация уровней детализации | ✗ **и не будет** | это авторство, а не оптимизация: Правило 11. Уровни, которые автор сделал сам, мы ПОКАЗЫВАЕМ и даём переключить (`scene/lod-levels`) |
| Упрощение сетки (decimation) | ✗ **и не будет** | переиграть Blender в авторстве нельзя; граница проекта — `docs/MISSION.md` |
| Конвертация в USDZ и другие форматы | ✗ | только glTF/GLB |

Всего правил обработки — **22**, в `addons/gltf/rules.mts`. Число сверяется командой:
`node -e "import('./addons/gltf/rules.mjs').then(m => console.log(m.RULES.length))"`.

## Движки и площадки

Две разные оси (`docs/ARCHITECTURE.md` §4g): движок — чем модель РИСУЕТСЯ,
площадка — КУДА она уезжает. Оба — данные (`engines/*.json`, `profiles/*.json`),
добавление не требует правки кода.

| Движок | Состояние |
|---|---|
| Three.js | включён |
| model-viewer | включён (2026-08-10) |
| Babylon.js | 0.3.0, см. `ROADMAP.md` §5g |
| PlayCanvas | не написан, технически подходит |
| Unity, Unreal | не будет — если понадобится, сообщество сделает профиль само |

| Площадка | Состояние |
|---|---|
| Прочерк («без площадки») | выбор по умолчанию; пороги общевебовые, из Khronos glTF Asset Auditor |
| Своя площадка (свой профиль) | ✓ (2026-08-12): JSON-файл в папке рядом с настройками приложения (`%APPDATA%/Tanyra3D/profiles` и аналоги; путь можно задать переменной `TANYRA3D_PROFILES_DIR`). Появляется в списке без перезапуска. Путь в окне — кнопка: открывает папку в проводнике. Пороги без источника помечаются «ваш порог, из вашего профиля». Файл с чужим id встроенную площадку не подменяет |
| Создание своей площадки из приложения | ✓ (2026-08-13): «Настройки» → «Создать свою площадку…». Спрашивает название, движок, описание, список опций и до шести чисел; пустое поле означает «порога нет». Своя площадка открывается на правку и удаляется там же; встроенную ни изменить, ни удалить нельзя. Если своя площадка уже выбрана в панели, окно открывается сразу на ней |
| Своя площадка вычитает опции | ✓ (2026-08-13): в форме все возможности движка включены, снятая галочка означает «эта площадка такого не читает» — и опция исчезает из панели совсем, без серых кнопок и объяснений. Объявлять возможности площадка не может, только вычитать: список того, что переваривается, принадлежит движку |
| Обмен площадками | ✓ (2026-08-13): «Открыть файл…» и «Сохранить в файл» в том же окне. Ходит сам `.json`, поэтому доезжает и то, чего форма не спрашивает: жёсткий предел, ссылка на источник, список вычитаемых опций. Встроенную площадку выгрузить нельзя; принесённый файл с именем встроенной получает своё имя и её не подменяет |
| Shopify | включена (2026-08-10, движок model-viewer) |
| VNTANA | включена (2026-08-18, движок three.js). Draco эта площадка не читает вовсе, поэтому опция не предупреждает, а исчезает |
| Google Store (карточка товара) | включена (2026-08-18, движок model-viewer) |

**Порогов без источника в профилях нет.** Неподтверждённые убраны, оставшиеся имеют поле
`source` со ссылкой на документ, и ссылка показывается пользователю. Метрика без порога не
исчезает — значение измеряется и показывается, оценка не выносится. Разбор:
`docs/БЮДЖЕТЫ_источники.md`.
