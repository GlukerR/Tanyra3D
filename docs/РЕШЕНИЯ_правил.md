# Решения правил: что приложение делает с моделью

> **Файл генерируется.** Не править руками: `node _work/gen-decisions.mjs`.
> Источник — метаданные правил в `addons/gltf/rules.mts` и каталоги `addons/gltf/messages/`.

Свод существует ради одной проверки — **на разногласия**. Правило 11 (`CLAUDE.md`)
говорит: мы оптимизатор, а не редактор, и граница проходит по вопросу «мог ли человек
сделать это НАМЕРЕННО?». Колонка «Замысел» отвечает на него для каждого правила.
Если где-то стоит ⛔ у правила, которое срабатывает само, — это дефект, и его видно
с одного взгляда.

- **⛔ ДА** — это замысел автора. Трогаем только по явной просьбе, с названной ценой
  и пометкой необратимости (узкое исключение Правила 11).
- **⚠️ частично** — содержание остаётся, теряется точность или качество.
- **✅ нет** — редактор наплодил это сам; убираем молча.

Правил всего: 22.

## Текстуры

| Правило | Когда срабатывает | Замысел | Обратимо | Потери |
|---|---|---|---|---|
| **Текстуры из одного цвета**<br>`textures/flat` | вместе с «Безопасными оптимизациями» | ✅ нет — следствие экспорта | нет | none |
| **Уменьшение текстур**<br>`textures/resize` | по выбору из группы «texture-size» | ⛔ ДА — замысел, удаляется только по явной просьбе | нет | significant |
| **Текстуры → KTX2/UASTC**<br>`textures/ktx2` | по галочке «ktx2» | ⚠️ частично — теряется точность, не содержание | да | minor |
| **Текстуры → WebP**<br>`textures/webp` | по галочке «webp» | ⚠️ частично — теряется точность, не содержание | да | minor |

- `textures/flat` — цвет сохраняется побайтно; меняется только разрешение, которое в заливке одним цветом ничего не значит
- `textures/resize` — уменьшается только то, что крупнее выбранного размера; пропорции сохраняются
- `textures/ktx2` — UASTC --level 2 --zstd 18 без RDO — почти без потерь, по выбору пользователя
- `textures/webp` — качество берётся от самого исходника: то, что пришло без потерь, кодируется без потерь, а сжатое — на его же качестве, не выше и не ниже; кодируются все текстуры модели
