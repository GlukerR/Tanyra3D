# Идеи для фич — glb_web_optimize

> Пресеты, вьюверы, интеграции с платформами. Отсортировано по приоритету и слоям разработки.

---

## Пресеты и сохранение конфигураций

**Текущий статус:** Идея

- **Функция:** Пользователь выбирает настройки оптимизации один раз, система сохраняет как именованный пресет.
- **Примеры:** "Shopify Quick", "Three.js Web Optimal", "Mobile Conservative"
- **UI:** Вкладки в интерфейсе (как браузерные вкладки).
- **Слой:** v0.2+ (после первого MVP)

---

## Вьювер с поддержкой всех движков

**Текущий статус:** Концепт (частично используется существующий Three.js-просмотрщик)

- **Идея:** Вьювер показывает не только модель, но и все варианты сжатия/компрессии (Draco, Meshopt, UASTC, ETC1S).
- **Интерактивность:** Пользователь выбирает сжатие во вьювере → система говорит, какие движки его поддерживают.
  - Если выбрал Draco, но движок его не поддерживает → красный флаг + рекомендация переоптимизировать.
- **Примечание:** Вьювер Three.js уже переиспользуется (см. [[3D Viewer — Three.js просмотрщик GLB]]).
- **Слой:** v0.2+ (интеграция в web-interface)

---

## Поддержка платформ: E-commerce (WB, Amazon, Shopify)

**Текущий статус:** Частично (Shopify есть, нужны остальные)

- **Задача:** Расширить профили платформ под:
  - **Wildberries (WB)**
  - **Amazon** (3D-каталог)
  - **Shopify** (уже есть)
- **Объединение:** Если WB и Amazon имеют одинаковые требования по бюджетам → упростить логику.
- **Проблема с USDZ:** Для iOS AR (Quick Look) нужна USDZ-экспорт, требует лицензии Apple / Pixar инструментов (macOS/Python) — **требует изучения для open-source**.
- **Слой:** v0.2–0.3 (добавлять профили по одному)

## Браузерное расширение (Browser Extension)

**Текущий статус:** Идея, не в приоритете

- **Функция:** Расширение Chrome/Firefox говорит художнику о проблемах 3D-моделей прямо на сайте.
  - Когда сайт загружает GLB → расширение анализирует и показывает отчёт: "Модель 4.2 МБ, можно оптимизировать на 60%".
  - Ссылка на full-аудит в нашем инструменте.
- **Использование:** Интеграция, помощь в обнаружении моделей для оптимизации.
- **Слой:** Далёкая цель (§7 из ROADMAP)

---

## Вьювер с поддержкой экспорта под конкретные движки

**Текущий статус:** Концепт

- **Фича:** Вьювер не просто показывает модель, а позволяет выбрать целевой движок (Unity, Unreal, Three.js) и сразу видит, как модель будет выглядеть в его ограничениях.
- **Примеры:**
  - "Как это будет в Unreal?" → переключить на физику Unreal, шейдеры, лимиты.
  - "Как это будет на Quest?" → включить ограничения по VRAM, полигонам.
- **Слой:** v0.3+ (после базовой поддержки движков)

---

## Сравнение моделей (Before/After)

**Текущий статус:** Частично готово (three.js-просмотрщик)

- **Функция:** Рядом две модели — исходная и оптимизированная. Синхронизированная камера, overlay с разницей.
- **Примечание:** Уже используется в существующем вьювере, нужна интеграция в web-interface v0.1.0.
- **Слой:** v0.1.0 (MVP)

## Интеграции с пайплайнами

**Текущий статус:** Идея

- **GitHub Action:** Автоматически оптимизировать 3D в CI/CD при загрузке в репозиторий.
- **Blender Plugin:** Прямо из Blender → File → Optimize for Web.
- **Shopify App:** Автоматическая нормализация моделей при загрузке в магазин.
- **Слой:** v0.3–0.4 (интеграции)

---

## Batch-обработка (будущее)

**Текущий статус:** Отложено

- **Не для v0.1.0** (слишком сложно для первого MVP).
- **Будущая фича:** Папка с 100 GLB → выполнить оптимизацию для всех, получить отчёт по каждому.
- **Слой:** v0.2–0.3 (после стабилизации одиночной обработки)
