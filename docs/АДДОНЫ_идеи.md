# Идеи для аддонов — glb_web_optimize

> Расширения, плагины, интеграции. Большая часть может быть создана сообществом.

---

## Браузерное расширение (Browser Extension)

**Статус:** Идея для сообщества

- **Функция:** Chrome/Firefox-расширение, которое анализирует 3D-модели на сайтах.
- **Что показывает:** На странице загружена GLB → расширение говорит об оптимизации: размер, сжатие, проблемы.
- **Действие:** Ссылка на full-аудит в нашем инструменте.
- **Тип:** Плагин, точка расширения

---

## Blender Plugin

**Статус:** Идея для сообщества

- **Функция:** File → Export for Web → выбрать платформу → Blender вызывает наш оптимизатор прямо перед экспортом.
- **Преимущество:** Художник не переходит в другой инструмент.
- **Технология:** Python API Blender + вызов нашего CLI.
- **Тип:** Плагин, интеграция

---

## GitHub Action

**Статус:** Идея для сообщества

- **Функция:** При push GLB-файла в репозиторий → автоматически запустить оптимизацию, создать отчёт в PR.
- **Пример:** Разработчик загрузил новую модель → CI говорит: "Эта модель может быть оптимизирована на 40%, вот отчёт".
- **Интеграция:** С нашим API или локальным CLI в Docker-контейнере.
- **Тип:** Интеграция, GitHub Marketplace

---

## Shopify App

**Статус:** Идея для сообщества

- **Функция:** Когда мерчант загружает 3D-модель в Shopify-каталог → приложение автоматически проверяет и оптимизирует.
- **Результат:** Покупатель видит оптимизированную модель, загрузка быстрее.
- **Интеграция:** Shopify API + наш оптимизатор.
- **Монетизация:** Возможный вариант (платный план за batch-обработку).
- **Тип:** App, интеграция с платформой

---

## Unity/Unreal Import Plugin

**Статус:** Идея, требует тестирования

- **Функция:** Import glTF → выбрать профиль оптимизации → Asset загружается с лучшими настройками.
- **Преимущество:** Художник видит финальный результат в движке.
- **Технология:** C# (Unity) или C++ (Unreal) binding к нашему ядру.
- **Слой:** v0.3–0.4
- **Тип:** Plugin, интеграция

---

## Отчёты в SARIF-формате

**Статус:** Идея

- **Функция:** Экспортировать результаты анализа в SARIF (Static Analysis Results Format).
- **Использование:** Интеграция в IDE (VS Code, JetBrains) как статический анализ 3D-данных.
- **Тип:** Формат, интеграция с инструментами разработки

---

## Профили платформ как Community-driven пакеты

**Статус:** Идея для сообщества

- **Функция:** Вместо того чтобы мы прописывали все профили (Three.js, Shopify, Quest, etc.), сообщество может предлагать свои профили через pull-request.
- **Пример:** "Я оптимизирую для PlayCanvas → создал профиль PlayCanvas.json → сделал PR".
- **Механизм:** Профили — это data, не code, поэтому просто и понятно.
- **Преимущество:** Масштабируется через сообщество, не зависит от нас.
- **Тип:** Точка расширения, модель данных

---

## Baseline и Regression-detection

**Статус:** Идея для CI/CD

- **Функция:** Сравнить текущую оптимизацию с предыдущим baseline.
  - Например: модель стала тяжелее чем ожидалось → warning в CI.
- **Использование:** Убедиться, что не случайно сломалась оптимизация.
- **Интеграция:** GitHub, GitLab CI.
- **Тип:** Инструмент, CI/CD

---

## Material Reconstruction (Advanced)

**Статус:** Далёкая цель

- **Функция:** При конвертации OBJ/MTL → glTF автоматически реконструировать PBR-материалы.
  - OBJ приходит с диффузным текстурой и normale map → система пытается понять ORM.
- **Сложность:** Требует ML или эвристик.
- **Слой:** v1.0+ (не для MVP)
- **Тип:** Algorithm, addon

---

## VS Code Extension

**Статус:** Идея

- **Функция:** Прямо в VS Code видеть ошибки 3D-файлов (если они в монорепо).
  - Наводишь на GLB → сразу видишь: "Модель 4.2 МБ, нужна оптимизация".
- **Интеграция:** Language Server Protocol (LSP) + наш оптимизатор.
- **Тип:** IDE Extension

---

## Вебхуки для автоматизации

**Статус:** Идея для SaaS

- **Функция:** Вебхук для собственного API: отправить GLB → получить оптимизированный файл + отчёт.
- **Примеры:** Shopify Webhook при новой модели → автоматически обработать.
- **Слой:** SaaS (v0.3+)
- **Тип:** API, интеграция

---

Все аддоны следуют принципу: **низкий барьер к входу** — профили и плагины это data, а не code, поэтому сообщество может помогать даже без глубокого знания архитектуры.
