# Словарь формулировок — технический термин → человеческий язык

> Справочник для `web-interface` и текстов отчёта (`ai-assistant`). Принцип: интерфейс
> раскрывает намерения, а не алгоритмы. Технические детали доступны на 2-м уровне
> progressive disclosure (ARCHITECTURE §4c), но по умолчанию пользователь видит человеческую
> формулировку.
>
> Правило: НЕ пугать терминологией. Уровень 1 объяснения — на языке художника, не инженера.

---

## Общий принцип

| Вместо (инженерное) | Показывать (человеческое) |
|---|---|
| Aggressive mesh simplification | Рекомендуется |
| GPU Texture Allocation | Использование памяти |
| Reduce textures | Ваши текстуры 4096×4096 — для мобильной цели это ~64 МБ памяти. Уменьшить до 2048×2048? |
| Merge vertices | Найдено 321 дублированная вершина — их удаление снижает нагрузку на GPU |
| Vertex welding | Объединение совпадающих точек модели |
| Draco compression | Сжатие геометрии (нужен декодер на стороне движка — см. отчёт) |
| KTX2 / Basis | Сжатие текстур под видеопамять |
| Draw calls | Количество отдельных отрисовок за кадр |
| Triangulation | Разбиение граней на треугольники (нужно движкам) |

---

## Правила словаря

- Число + следствие вместо голого действия: не «уменьшить текстуры», а «4096→2048, экономия 75% памяти, на глаз незаметно».
- Слово «Рекомендуется» вместо названий агрессивных операций — сила решения прячется во 2-й уровень.
- Единицы — человеческие: МБ, пиксели, «штуки», а не байты и внутренние коды.
- Термин допустим, если рядом сразу его смысл в скобках (один раз), дальше можно термином.

## Что переводить, а что оставить английским (на решение Александра)

Ориентир — Blender: русскими становятся обычные слова, названия технологий остаются как
есть. Художник, который ищет ответ в интернете, должен искать по тому же слову, что видит
у нас. Переведённый термин ломает ровно это.

Три класса, и правило для каждого разное:

1. **Названия технологий — не переводить никогда.** Draco, Meshopt, KTX2, UASTC, ETC1S,
   glTF, EXT_mesh_gpu_instancing. Это имена собственные.
2. **Обычные слова — переводить.** «удалено», «объединено», «не применено», «рекомендуется».
3. **Термины ремесла — спорная зона.** Ниже таблица: что сейчас выбрано и что стоит
   обсудить. Колонка «решение» — под правку Александром.

| Термин | Сейчас в интерфейсе | Альтернатива | Решение |
|---|---|---|---|
| mesh | **меш** | сетка / модель | ? |
| draw calls | **отрисовки за кадр** | draw calls | ? |
| vertex weld | **совпадающие вершины склеены** | weld | ? |
| accessor | **блок данных** | accessor | ? спорно: «блок данных» ничего не говорит тому, кто полезет в спецификацию |
| skin | **скин** | скиннинг / привязка | ? |
| morph target | **морф-таргет** | морф / ключ формы | ? Blender говорит «shape key» |
| bounding box | **bounding box** | габаритный бокс | ? сейчас не переведён |
| node | **узел** | нода | ? |
| primitive | **примитив** | — | ? |
| degenerate triangle | **вырожденный треугольник** | — | принято |
| orphan vertex | **висящая вершина** | — | принято |
| prune | **чистка** | — | принято |
| dedup | **объединение одинаковых** | — | принято |

Проверка на каждый спорный случай: **по какому слову человек будет искать в интернете,
когда захочет разобраться?** Если по английскому — оставляем английское.
