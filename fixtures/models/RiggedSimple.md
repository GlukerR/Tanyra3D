# Golden Corpus — RiggedSimple

## Назначение

**Скелетная анимация — единственный случай, которого в корпусе не было вовсе.**

В корпусе есть морфы (`Morph Cube 01`) и анимация трансформов, но скинов с костями
нет ни одного. Это самый частый случай у персонажников и самый опасный для оптимизаций:
`join` должен пропускать узлы со скином, `weld` не должен ломать веса вершин, `meshopt`
с `quantizationVolume: 'scene'` при наличии скинов не должен расщеплять общий скин
на отдельные копии (TESTBUG-007).

Модель из Khronos glTF-Sample-Assets, специально создана для тестов скиннинга.
Цитата из README: «Start with this to test skinning.»

## Что должна проверить оптимизация

### Инварианты для скинов

- `join` пропускает узлы, привязанные к скину — сцена не ломается.
- `weld` и `dedup` не трогают `JOINTS_0` и `WEIGHTS_0` — веса остаются валидными.
- `meshopt` с авто-определением `quantizationVolume: 'scene'` (при наличии скинов)
  не расщепляет общий скин на отдельные копии.
- `resample` не портит анимацию скелета.
- `draco` сжимает геометрию без артефактов на стыках костей.

### Инварианты baseline-checkpoint

- `skins` не меняется после кодирования (был 1 — остался 1).
- `animations` не меняется.
- `triangles` не меняются (188 → 188) под meshopt; под draco допустимо небольшое
  расхождение (квантование), но не более нескольких единиц.

### Валидация

- Выходной GLB проходит валидатор Khronos без ошибок (на исходнике — 0 ошибок).

## После оптимизации необходимо проверить

- [ ] Треугольников 188 во всех режимах, кроме draco (допуск ±2).
- [ ] `skins` = 1 после любого набора флагов.
- [ ] `animations` = 1 после любого набора флагов.
- [ ] `['safe','join']` — `join` в `skipped` с kind `'unsafe'` (узлы со скином пропущены).
- [ ] `['safe','meshopt']` — `quantizationVolume: 'scene'`, скин не расщеплён.
- [ ] Выходной GLB под `['safe','meshopt']` проходит валидатор Khronos.

## Примечание

Это минимальная модель для тестов скиннинга — специально выбрана самой лёгкой из
Khronos-набора. Для более сложных случаев (несколько скинов, много костей, персонаж
с текстурами) рекомендуется добавить `RiggedFigure` (тоже CC BY 4.0, Cesium).
