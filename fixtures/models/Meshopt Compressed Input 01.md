# Golden Corpus — Meshopt Compressed Input 01

## Назначение

Тестовая модель для проверки обработки glTF файлов, которые уже содержат meshopt compression.

Модель используется для проверки корректной распаковки входной геометрии перед выполнением операций оптимизации.

---

## Происхождение и лицензия

Модель создана автором проекта вручную и распространяется с открытой лицензией.

## Исходное состояние

Файл содержит:

- EXT_meshopt_compression
- KHR_mesh_quantization
- EXT_texture_webp

Создан через:

glTF-Transform v4.2.1

---

## Проверяет

- корректную загрузку meshopt compressed geometry;
- корректную декомпрессию;
- сохранение геометрии после обработки;
- отсутствие повреждения атрибутов;
- совместимость с дальнейшей оптимизацией.

---

## После обработки проверить

- [ ] модель открывается;
- [ ] геометрия совпадает;
- [ ] количество мешей корректно;
- [ ] UV сохранены;
- [ ] нормали сохранены;
- [ ] итоговый GLB валиден.
