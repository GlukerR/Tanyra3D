# Golden Corpus — Cthulhu Stone 01

## Назначение

Тестовая сцена для проверки корректной обработки сложных анимированных моделей с Armature, Skinning и несколькими типами анимаций.

Модель представляет собой реальный старый 3D-ассет с историческими особенностями экспорта. Она намеренно используется как сложный тестовый пример для выявления ошибок, которые могут не проявляться визуально при обычной проверке структуры glTF.

Основная цель — проверить, что оптимизация не повреждает:

- скелет;
- skin weights;
- привязку меша к костям;
- анимацию костей;
- объектную анимацию;
- структуру узлов сцены.

## Исходное содержимое

### Геометрия

Модель представляет собой старый 3D-ассет:

- содержит скелетную структуру;
- содержит анимируемую геометрию;
- экспортирована не из современного оптимизированного пайплайна.

Модель намеренно сохранена в исходном состоянии, включая возможные особенности старого экспорта.

---

## Armature / Skinning

В сцене присутствует:

- Armature;
- система костей;
- Skinning;
- привязка меша к скелету.

Проверяется корректность работы с:

- joints;
- skin;
- inverse bind matrices;
- vertex weights.

---

## Анимации

Модель содержит два разных типа анимации.

### 1. Armature Animation

Анимация скелета.

Проверяет:

- движение костей;
- корректное влияние костей на меш;
- сохранение skin deformation.

---

### 2. Object Animation

Анимация объекта.

Тип движения:

- подъём и опускание объекта по вертикальной оси.

Проверяет:

- сохранение transform animation;
- корректную обработку node translation;
- работу нескольких типов анимаций одновременно.

---

## Что должна проверить оптимизация

### Skin Preservation

Ожидаемый результат:

- количество skin не изменилось;
- все joints сохранены;
- веса вершин не потеряны;
- модель деформируется так же, как до оптимизации.

---

### Animation Preservation

Ожидаемый результат:

Сохраняются:

- Armature animation;
- Object animation.

Обе анимации должны воспроизводиться независимо и корректно.

---

### Join / Flatten Safety

Проверить:

- нельзя объединить или изменить иерархию так, чтобы сломать skeleton;
- нельзя изменить индексы узлов без корректного обновления skin references;
- нельзя потерять связи между mesh и armature.

---

### Node Hierarchy Preservation

Проверить:

- сохранение структуры узлов;
- корректную работу вложенных объектов;
- отсутствие удаления необходимых узлов.

---

## После оптимизации необходимо проверить

- [ ] Модель открывается без ошибок.
- [ ] Armature присутствует.
- [ ] Все кости сохранены.
- [ ] Skin weights сохранены.
- [ ] Деформация меша совпадает с оригиналом.
- [ ] Анимация скелета работает.
- [ ] Анимация подъёма/опускания объекта работает.
- [ ] Обе анимации доступны после оптимизации.
- [ ] Количество animations не изменилось.
- [ ] Количество skins не изменилось.
- [ ] Иерархия узлов не повреждена.

## Примечание

Эта модель является частью Golden Corpus проекта и представляет собой не идеальный эталонный ассет, а практический стресс-тест.

В отличие от специально созданных минимальных тестовых моделей, данный файл отражает реальные проблемы старых 3D-экспортов: сложную структуру узлов, несколько типов анимации и потенциально опасные места для автоматической оптимизации.

Любое изменение результата должно быть воспроизводимым и объяснимым.
