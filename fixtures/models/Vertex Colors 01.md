# Golden Corpus — Vertex Colors 01

## Назначение

Тестовая сцена для проверки корректной обработки вершинных цветов (`COLOR_0`) и дополнительных цветовых атрибутов меша при выполнении операций оптимизации.

Модель предназначена для проверки сохранения, удаления, переиндексации и порядка color attributes после операций `weld`, `join`, `prune` и `strip-colors`.

---

## Происхождение и лицензия

Эта модель создана специально для проекта вручную в Blender.

Она не содержит сторонних моделей, геометрии или других ресурсов, защищённых авторским правом. Благодаря этому модель может свободно распространяться вместе с проектом, использоваться в автоматических тестах, публиковаться в открытом репозитории и модифицироваться без каких-либо лицензионных ограничений.

Цель модели — предоставить полностью открытый и воспроизводимый тест для проверки обработки вершинных цветовых атрибутов.

---

## Исходное содержимое

### Геометрия

* Один стандартный куб.
* Один материал.
* Без текстур.

---

## Color Attributes

В меше создано **два независимых цветовых атрибута**.

### Color Attribute 1 — `Color_Main`

Содержит пользовательскую раскраску:

* одна вершина — чёрная;
* одна вершина — синяя;
* одна вершина — зелёная;
* одна вершина — красная;
* четыре нижние вершины намеренно оставлены без изменения.

Этот слой проверяет сохранение реальных пользовательских данных.

---

### Color Attribute 2 — `Color_White`

Содержит одинаковое значение для всех вершин:

* все вершины белые.

Этот слой проверяет:

* сохранение дополнительных color attributes;
* сохранение порядка атрибутов;
* отсутствие автоматического удаления «однотонных» слоёв;
* корректную работу переиндексации вершин.

---

## Визуальная схема

Верхние вершины окрашены, нижние оставлены без изменения, второй слой полностью белый.

---

## Что должна проверить оптимизация

### Multiple Color Attributes Preservation

Ожидаемый результат:

* сохранены оба color attribute;
* `Color_Main` сохранил все индивидуальные цвета;
* нижние вершины остались неизменными;
* `Color_White` остался полностью белым;
* порядок атрибутов не изменился.

---

### Strip Vertex Colors (если реализовано)

При использовании режима `strip-colors` ожидается:

* удалены все color attributes;
* геометрия не изменилась;
* остальные атрибуты меша сохранены.

---

### Weld / Join

Если выполняются операции объединения вершин или мешей, необходимо убедиться, что:

* оба color attribute корректно переиндексированы;
* цвета не перепутались между вершинами;
* второй слой не потерян;
* не произошло повреждения данных после сварки вершин.

---

### Prune

Проверить, что `prune` не удаляет `Color_White` только потому, что он содержит одинаковые значения.

---

## После оптимизации необходимо проверить

* [ ] Геометрия полностью совпадает с исходной.
* [ ] Присутствуют оба color attribute.
* [ ] Порядок атрибутов сохранён.
* [ ] Цвета `Color_Main` сохранены.
* [ ] Нижние вершины `Color_Main` не изменились.
* [ ] `Color_White` остался полностью белым.
* [ ] После `strip-colors` оба слоя удалены.
* [ ] Размер файла уменьшился только при использовании правил, затрагивающих Vertex Colors.

---

## Ожидаемое поведение

| Режим              | `Color_Main` | `Color_White` |
| ------------------ | ------------ | ------------- |
| Без `strip-colors` | Сохранён     | Сохранён      |
| С `strip-colors`   | Удалён       | Удалён        |

---

## Примечание

Данная сцена является частью Golden Corpus проекта и предназначена исключительно для проверки работы с несколькими вершинными цветовыми атрибутами одновременно.

Минимальная геометрия позволяет быстро локализовать ошибки, связанные с `COLOR_0`, дополнительными color attributes и их переиндексацией, без влияния текстур, морф-таргетов, скиннинга или сложных материалов.
