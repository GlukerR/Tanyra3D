# Golden Corpus — Instance Grid 01

## Назначение

Тестовая сцена для проверки обнаружения повторяющейся геометрии и оптимизаций, связанных
с одинаковыми объектами.

**Что в СЦЕНЕ Blender и что в ФАЙЛЕ — разные вещи, и в этом вся ценность заготовки.**
В сцене был один куб и модификатор Array. В экспортированном GLB инстансов нет: Array
ЗАПЕКАЕТ смещение каждой копии прямо в координаты вершин, поэтому в файле лежат **625
отдельных мешей**, у каждого свой набор вершин, а узлы стоят в одной точке.

Замер 2026-08-23: из 625 мешей **623 — одна и та же форма**, отличие только в сдвиге;
оставшиеся два отличаются порядком вершин.

Это самая обычная поставка от художника, и до 2026-08-23 мы её не понимали: склейка
одинаковых не срабатывала (данные и правда разные), инстансинг не срабатывал тем более.
Теперь копии узнаются ПО ФОРМЕ — координаты приводятся к общему началу, — и заготовка
проверяет именно этот путь.

Александр 2026-08-23: «это одинаковые кубы. мы никак не можем начать их тоже инстансить?
если человек пришлёт такую же модель мы не сможем понять что это одинаковые модели никак?»

### Замер после починки

| набор | вызовов отрисовки | мешей | треугольников | файл |
|---|---|---|---|---|
| `safe` | 625 → 625 | 625 → 625 | 7500 → 7500 | 971 → 1031 КБ |
| `safe` + `instance` | 625 → **10** | 625 → **10** | 7500 → 7500 | 971 → **96 КБ** |
| `safe` + `join` | 625 → **1** | 625 → 1 | 7500 → 7500 | 971 → 587 КБ |

Треугольники не меняются ни при одном наборе — это та же модель. Склейка мешей (`join`)
даёт меньше вызовов, инстансинг — вдесятеро меньший файл: у первой все 625 копий геометрии
остаются в файле, у второго остаётся одна.

## Происхождение и лицензия

Эта модель создана специально для проекта вручную в Blender.

Она не содержит сторонних моделей, геометрии или других ресурсов, защищённых авторским правом. Благодаря этому модель может свободно распространяться вместе с проектом, использоваться в автоматических тестах, публиковаться в открытом репозитории и модифицироваться без каких-либо лицензионных ограничений.

Цель модели — предоставить полностью открытый и воспроизводимый тест для проверки алгоритмов работы с повторяющейся геометрией.

---

## Исходное содержимое

### Геометрия

- Один базовый куб.
- Один материал.
- Одна текстура.

---

### Повторения

Куб размножен с помощью двух модификаторов Array:

- первый Array создаёт 25 экземпляров;
- второй Array размножает получившийся ряд ещё 25 раз.

В результате сцена содержит около **625 одинаковых экземпляров** одного объекта.

Экземпляры расположены с небольшим смещением по двум осям, чтобы избежать полного наложения друг на друга.

---

### Материалы

Все экземпляры используют:

- один и тот же материал;
- одну и ту же текстуру.

Это позволяет исключить влияние материалов и сосредоточиться только на обработке геометрии.

---

## Что должна проверить оптимизация

### Instance Detection

Ожидаемый результат:

- обнаружить большое количество повторяющихся экземпляров;
- корректно обработать повторяющуюся геометрию;
- не изменить внешний вид сцены.

---

### EXT_mesh_gpu_instancing (если реализовано)

Если оптимизатор поддерживает расширение `EXT_mesh_gpu_instancing`, сцена является эталонным тестом для его генерации.

Ожидаемый результат:

- повторяющиеся объекты преобразованы в GPU Instancing;
- количество отдельных мешей уменьшилось;
- визуальный результат полностью совпадает с исходным.

---

### Join

Если используется объединение геометрии (`join`), необходимо убедиться, что:

- объединение не ухудшает результат по сравнению с инстансингом;
- геометрия не повреждается;
- количество треугольников остаётся неизменным.

---

### Memory Optimization

Большое количество повторов позволяет оценить:

- уменьшение размера файла;
- уменьшение количества узлов;
- уменьшение количества мешей;
- эффективность повторного использования данных.

---

## После оптимизации необходимо проверить

- [ ] Внешний вид сцены полностью совпадает с исходной.
- [ ] Все экземпляры находятся на своих местах.
- [ ] Количество треугольников не изменилось.
- [ ] Количество материалов не изменилось.
- [ ] Количество текстур не изменилось.
- [ ] Если используется GPU Instancing — расширение создано корректно.
- [ ] Если GPU Instancing не используется — оптимизация не ухудшила структуру сцены.
- [ ] Размер файла уменьшился (если применимы соответствующие правила).

---

## Примечание

Эта сцена является частью Golden Corpus проекта и предназначена исключительно для проверки алгоритмов обработки большого количества одинаковой геометрии.

В отличие от Dirty Cube, она не содержит намеренно добавленного "мусора". Все объекты являются валидными и используются для оценки эффективности алгоритмов обнаружения повторений и создания инстансов.
