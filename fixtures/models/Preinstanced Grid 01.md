# Golden Corpus — Preinstanced Grid 01

## Назначение

Модель, которая **уже содержит `EXT_mesh_gpu_instancing` на входе**.

Проверяет обратную сторону инстансинга: мы умеем его создавать (`Linked Duplicates Grid 01`),
но должны ещё и не разваливать чужой. Инстансированная сцена — это один узел, несущий N
наборов трансформов; наивный обход по узлам насчитает в ней в двенадцать раз меньше
треугольников, чем рисуется на экране, и «оптимизация» отчитается о несуществующем выигрыше.

Это последний пробел приоритета 1 из `fixtures/ЧТО_ДОБАВИТЬ_В_КОРПУС.md`.

---

## Происхождение и лицензия

Производная от `Linked Duplicates Grid 01.glb` (модель автора проекта): результат прогона
`advancedFeatures: ['safe', 'instance']` нашим же пайплайном. Сторонних ресурсов не
содержит, распространяется свободно.

Воспроизводится одной командой:

```bash
node _work/make-fixtures.mjs
```

## Исходное содержимое

Проверено чтением файла 2026-07-28.

| Метрика | Значение |
|---|---|
| Байты | 2 532 |
| Узлы | 1 |
| Меши | 1 |
| Draw calls | 1 |
| Треугольники | **144** |
| Расширения | `EXT_mesh_gpu_instancing` |

Один узел с расширением, несущим двенадцать наборов трансформов. Геометрия — один куб
на 12 треугольников; 144 = 12 × 12.

---

## Что должна проверить оптимизация

### Поправка на экземпляры в метриках

Главное. `instanceCountOf()` в `addons/gltf/metrics.mjs` умножает треугольники и вершины
на число экземпляров расширения. Без этой поправки счёт шёл бы по одному обходу узла и
дал бы **12** вместо 144.

Ожидаемый результат: `metrics.before.triangles === 144` уже на passthrough. Если поправка
сломается, это единственная модель корпуса, которая покажет ошибку сразу, до всякой
оптимизации.

`drawCalls` при этом равен **1** и умножаться не должен — в этом и смысл инстансинга.

### Passthrough не трогает расширение

Измерено: `advancedFeatures: []` → `status: 'ok'`, узлы 1 → 1, треугольники 144 → 144,
`EXT_mesh_gpu_instancing` на месте.

### `safe` не разваливает инстансинг

Измерено: `['safe']` → узлы 1 → 1, draw calls 1 → 1, треугольники 144 → 144.
`prune` не должен счесть расширение мусором, `dedup` — схлопнуть трансформы.

---

## После оптимизации необходимо проверить

- [ ] `metrics.before.triangles === 144` (а не 12) — поправка на экземпляры работает.
- [ ] `metrics.before.drawCalls === 1` — draw calls не умножаются.
- [ ] После passthrough и после `safe` расширение `EXT_mesh_gpu_instancing` на месте.
- [ ] Узлов по-прежнему 1, треугольников 144.
- [ ] Выходной GLB проходит валидатор Khronos без ошибок.

---

## Примечание

Пара `Linked Duplicates Grid 01` → `Preinstanced Grid 01` замкнута: первая проверяет
создание инстансинга, вторая — сохранение уже существующего. Вторая получается из первой
нашим же кодом, поэтому если сломается создание, сломается и воспроизведение фикстуры.
