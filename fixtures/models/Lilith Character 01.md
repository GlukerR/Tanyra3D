# Golden Corpus — Lilith Character 01

## Назначение

Тестовая сцена для проверки обработки реального персонажного 3D-ассета с большим количеством объектов, материалов, узлов сцены, Armature и анимаций.

Модель используется как production-like тест для проверки корректности оптимизации сложных игровых персонажей.

В отличие от минимальных тестовых моделей Golden Corpus, данный файл представляет собой реальный ассет с типичной структурой экспорта из DCC-инструментов.

## Исходное содержимое

### Тип модели

Персонажный 3D-ассет.

Содержит:

- персонажную геометрию;
- Armature;
- Skinning;
- анимации;
- несколько частей меша;
- материалы;
- текстуры;
- вспомогательные узлы сцены.

---

## Геометрия

Модель состоит из большого количества отдельных мешей.

Проверяется работа с:

- множеством объектов;
- раздельными частями персонажа;
- большим количеством draw calls;
- сохранением структуры персонажа.

Примерные элементы:

- тело;
- волосы;
- одежда;
- аксессуары;
- дополнительные детали.

---

## Armature / Skinning

Модель содержит:

- скелет;
- привязку мешей к костям;
- веса вершин.

Используется для проверки:

- сохранения skin;
- корректности joints;
- сохранения деформации персонажа.

---

## Анимации

Модель содержит несколько состояний.

### T-Pose

Используется как базовая поза персонажа.

Проверяет:

- корректное сохранение исходного состояния;
- наличие базового клипа.

---

### Idle / Walk Animation

Присутствует циклическая анимация движения персонажа.

Проверяет:

- сохранение animation clips;
- работу bone animation;
- корректное воспроизведение после оптимизации.

---

## Материалы и текстуры

Модель содержит несколько материалов и текстур.

Проверяется:

- сохранение связей material → texture;
- корректная работа с повторным использованием текстур;
- отсутствие потери материалов при очистке.

Особый интерес:

- возможные повторяющиеся Base Color текстуры;
- несколько материалов с похожими ресурсами.

---

## Иерархия сцены

Модель содержит большое количество узлов сцены.

В том числе:

- Empty;
- вспомогательные узлы;
- объекты для отдельных частей персонажа.

Проверяется:

- корректность prune;
- сохранение необходимых узлов;
- отсутствие удаления важных элементов скелета.

---

## Что должна проверить оптимизация

### Skin Preservation

Ожидаемый результат:

- количество skin не изменилось;
- веса вершин сохранены;
- деформация персонажа осталась корректной.

---

### Animation Preservation

Ожидаемый результат:

Сохраняются:

- базовая поза;
- idle animation;
- остальные animation clips.

---

### Material Cleanup

Проверяется:

- удаление реально неиспользуемых материалов;
- отсутствие удаления материалов, используемых персонажем.

---

### Texture Optimization

Проверяется:

- корректная обработка текстур;
- возможное объединение одинаковых ресурсов;
- отсутствие визуальных изменений.

---

### Node Cleanup

Проверяется осторожность операций:

- prune;
- flatten;
- hierarchy optimization.

Особое внимание:

Empty и вспомогательные узлы могут быть частью структуры персонажа и не должны удаляться без проверки.

---

- [ ] Персонаж выглядит идентично оригиналу.
- [ ] T-Pose работает.
- [ ] Idle animation работает.
- [ ] Skin deformation не повреждена.

- [ ] Все материалы сохранены.

- [ ] Количество animation clips не изменилось.
- [ ] Количество skins не изменилось.
- [ ] Скелет не повреждён.
- [ ] Не удалены необходимые Empty и узлы.

## Примечание

Эта модель является частью Golden Corpus проекта и представляет собой реалистичный тестовый сценарий для персонажных ассетов.

Она дополняет минимальные тесты:

- Morph Cube;
- Dirty Cube;
- Instance Grid;

и используется для проверки поведения оптимизатора на сложной реальной модели.

Главная ценность модели — большое количество связанных элементов: мешей, узлов, материалов, костей и анимаций.
